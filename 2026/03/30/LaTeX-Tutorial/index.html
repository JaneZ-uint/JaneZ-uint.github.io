    LaTeX-Tutorial

    4 minute read

    Published: March 30, 2026

    Read this post in English

    lz时隔大半年重新拾起LaTeX写算法作业，发现符号忘的稀碎，于是特出此tutorial，记录一些常用的LaTeX数学符号和环境，方便以后查阅。

    LaTeX Tutorial

    1. 基础语法

    1.1 文档结构

    \documentclass{article}  % 文档类型
\usepackage{amsmath}     % 数学包
\usepackage{amssymb}     % 数学符号包

\begin{document}
% 文档内容
\end{document}

    1.2 文本格式

    \textbf{粗体}           % 粗体
\textit{斜体}           % 斜体
\underline{下划线}      % 下划线
\texttt{等宽字体}       % 打字机字体

    2. 数学模式

    2.1 行内公式与行间公式

    行内公式: $E = mc^2$
行间公式: $$E = mc^2$$
或者:
\[ E = mc^2 \]

    2.2 equation 环境

    \begin{equation}
  E = mc^2
\end{equation}

% 不编号
\begin{equation*}
  E = mc^2
\end{equation*}

    3. 常用数学符号

    3.1 希腊字母

    小写字母:

    \alpha    α       \beta     β       \gamma    γ
\delta    δ       \epsilon  ε       \zeta     ζ
\eta      η       \theta    θ       \iota     ι
\kappa    κ       \lambda   λ       \mu       μ
\nu       ν       \xi       ξ       \pi       π
\rho      ρ       \sigma    σ       \tau      τ
\upsilon  υ       \phi      φ       \chi      χ
\psi      ψ       \omega    ω

    大写字母:

    \Gamma    Γ       \Delta    Δ       \Theta    Θ
\Lambda   Λ       \Xi       Ξ       \Pi       Π
\Sigma    Σ       \Upsilon  Υ       \Phi      Φ
\Psi      Ψ       \Omega    Ω

    3.2 运算符

    基本运算:

    +         加       -         减       \times    ×
\div      ÷       \pm       ±       \mp       ∓
\cdot     ·       \ast      *       \star     ⋆

    关系运算符:

    =         =       \neq      ≠       <         <
>         >       \leq      ≤       \geq      ≥
\ll       ≪       \gg       ≫       \approx   ≈
\equiv    ≡       \sim      ∼       \simeq    ≃
\propto   ∝       \in       ∈       \notin    ∉
\subset   ⊂       \subseteq ⊆       \supset   ⊃

    逻辑符号:

    \land     ∧       \lor      ∨       \neg      ¬
\implies  ⟹       \iff      ⟺       \forall   ∀
\exists   ∃       \nexists  ∄       \emptyset ∅

    3.3 上下标

    x^2              % 上标
x_i              % 下标
x^{2y}           % 多字符上标
x_{ij}           % 多字符下标
x_i^2            % 同时使用上下标

    3.4 分数与根号

    \frac{a}{b}      % 分数
\dfrac{a}{b}     % 显示模式分数
\tfrac{a}{b}     % 文本模式分数
\sqrt{x}         % 平方根
\sqrt[n]{x}      % n次根

    3.5 求和、积分、极限

    \sum_{i=1}^{n}          % 求和
\prod_{i=1}^{n}         % 连乘
\int_{a}^{b}            % 积分
\iint                   % 二重积分
\iiint                  % 三重积分
\oint                   % 环路积分
\lim_{x \to \infty}     % 极限

    3.6 括号

    ()                       % 小括号
[]                       % 中括号
\{\}                     % 大括号
\langle \rangle          % 尖括号 ⟨⟩
\lfloor \rfloor          % 下取整 ⌊⌋
\lceil \rceil            % 上取整 ⌈⌉

    自动调整大小:

    \left( \frac{a}{b} \right)
\left[ \frac{a}{b} \right]
\left\{ \frac{a}{b} \right\}

    4. 矩阵

    4.1 基本矩阵

    % 无括号矩阵
\begin{matrix}
  a & b \\
  c & d
\end{matrix}

% 圆括号矩阵
\begin{pmatrix}
  a & b \\
  c & d
\end{pmatrix}

% 方括号矩阵
\begin{bmatrix}
  a & b \\
  c & d
\end{bmatrix}

% 花括号矩阵
\begin{Bmatrix}
  a & b \\
  c & d
\end{Bmatrix}

% 竖线矩阵
\begin{vmatrix}
  a & b \\
  c & d
\end{vmatrix}

% 双竖线矩阵
\begin{Vmatrix}
  a & b \\
  c & d
\end{Vmatrix}

    4.2 省略号

    \dots    % 底部省略号
\cdots   % 中部省略号
\vdots   % 竖直省略号
\ddots   % 对角省略号

    5. 多行公式

    5.1 align 环境

    \begin{align}
  x &= a + b \\
  y &= c + d \\
  z &= e + f
\end{align}

    5.2 cases 环境

    f(x) = \begin{cases}
  x^2 & \text{if } x \geq 0 \\
  -x  & \text{if } x < 0
\end{cases}

    5.3 split 环境

    \begin{equation}
\begin{split}
  f(x) &= (x+1)^2 \\
       &= x^2 + 2x + 1
\end{split}
\end{equation}

    \mathbb{R}          % 黑板粗体 ℝ

    7. 空格控制

    a\ b              % 普通空格
a\,b              % 小空格
a\:b              % 中等空格
a\;b              % 大空格
a\quad b          % 1em 空格
a\qquad b         % 2em 空格
a\!b              % 负空格

    8. 文本注释

    \text{文本内容}           % 在公式中插入文本
\mbox{文本内容}           % 文本框

    9. 重音符号

    \hat{a}      â       \bar{a}      ā
\tilde{a}    ã       \dot{a}      ȧ
\ddot{a}     ä       \vec{a}      ā⃗
\widehat{ab}         \widetilde{ab}

    10. 常用定理环境

    \usepackage{amsthm}

\newtheorem{theorem}{Theorem}
\newtheorem{lemma}{Lemma}
\newtheorem{proposition}{Proposition}
\newtheorem{corollary}{Corollary}
\newtheorem{definition}{Definition}

\begin{theorem}
  定理内容
\end{theorem}

\begin{proof}
  证明内容
\end{proof}

    11. 常用技巧

    11.1 对齐

    \begin{aligned}
  &\text{左对齐} \\
  &\text{内容}
\end{aligned}

    11.2 编号控制

    \tag{1}              % 手动标签
\notag               % 取消编号
\nonumber            % 取消编号

    11.3 颜色

    \usepackage{xcolor}
\textcolor{red}{红色文本}
\colorbox{yellow}{黄色背景}

    12. 最佳实践

    1. 括号匹配: 使用 \left 和 \right 自动调整括号大小
    2. 长公式: 使用 align 或 split 环境分行
    3. 矩阵: 选择合适的括号类型
    4. 间距: 适当使用 \, \quad 等调整间距
    5. 文本: 在公式中使用 \text{} 插入文本
    6. 符号: 复杂符号使用宏定义简化输入
    % 自定义命令示例
\newcommand{\R}{\mathbb{R}}
\newcommand{\norm}[1]{\left\| #1 \right\|}
